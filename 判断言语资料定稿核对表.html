2. 各类错因的核对标准（AI 是否定得准）

  • 理解偏差：核对是否真为"没看透关系/抓漏信息"，而非"概念记错"。若其实是你概念不清，应改标概念混淆（更符合"定义/类比边界"类）。
  • 方法不当：核对是否真为"该题题型的方法/步骤不会"。若你其实会做、只是看错问法，应改审题失误（降级）。
  • 概念混淆：核对是否真为"两个概念/名词/规律类型没分清"。重点看定义判断（语词边界）、类比（包容/并列/交叉）。
  • 粗心：若图推/逻辑其实方法对但数错/看漏，保留"粗心"（C级，二刷放后面）。

    • 3. 二刷优先顺序（B 级为主）

1. 类比—理解47（对应31/并列17/包容16 是重灾区）

2. 定义—理解37 + 概念21

3. 逻辑—理解25 + 方法24（翻译/排列路径）

4. 图形—理解23 + 方法15 + 概念10（需配图，重错因时结合清晰图）

2. 各类错因的核对标准

  • 逻辑填空：AI 若标【理解偏差】→ 大概率应改【概念混淆】（这是词汇/成语辨析，不是读不懂）。判定：若你知道词义只是两个相近词没选对→概念混淆；若文段逻辑没读懂→理解偏差。
  • 片段阅读：若【理解偏差】→ 核对是"主旨没抓准"还是"过度脑补"。前者保留理解偏差，后者可考虑方法不当（没按结构找重点）。
  • 方法不当：核对是否真为"中心理解/标题/排序的方法论"没掌握；若只是粗心看漏，改为粗心。

    • 3. 二刷优先顺序

1. 逻辑填空·概念混淆（词语辨析，属 A 级硬伤，最该优先）

2. 片段·理解偏差58（主旨/结构）

3. 语句表达（理解8+方法4）

2. 各类错因的核对标准（重点：范围题）

  • 区间/范围题（"介于多少之间""在哪个范围内"）：AI 若标【粗心/审题】→ 核对是否真为B↔C 区间越界。若是，这是你资料分析最稳定的丢分点（不是粗心，是区间边界判断方法不对），建议升级为"方法不当"并专项练区间判断。
  • 理解偏差：核对是否真为"材料没读全/单位没对上"，还是"公式列错"。列式错→方法不当；单位/数量级→理解偏差或粗心。
  • 方法不当：核对是否为"基期/现期、增长率/增长量、比重/倍数、年均"等公式误用。
  • 粗心：若实为"会算但算错一位/看错"，保留粗心（C 级）。

    • 3. 二刷优先顺序

1. B 级 114（综合/文字 的 理解33+23、方法23+21）——材料读取 + 列式

2. C 级 46 中的"区间/临界"题——虽标 C，但这是最值得二刷突破的（B↔C 定势），务必专项练"介于多少"。

3. A 级 22（概念：基期/现期、同比/环比、增长率/增长量）——少量但硬伤。

四、三模块统一复核口诀（快速过完）

1. 看选项层级：你常错到"相邻/最绝对"的那个选项 → 关注该题的区间/程度定势（资料 B↔C；判断最绝对；言语似而非）。

2. 看错误类别是否"该重的不重"：言语逻辑空多别标"理解偏差"、资料范围题别标"粗心"——这两类要主动升级到"概念混淆/方法不当"，否则二刷清单会漏。

3. C 级可放后：粗心/审题/无需错因 是"会而不对/根本没错"，二刷优先级最低，人工定稿可快速跳过。
